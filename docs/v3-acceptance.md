# Auto Office v3 — Acceptance Matrix

## Overview and Status

This document defines the authoritative, machine-checkable acceptance matrix for Auto Office v3. It enumerates all requirements across the three governing issues:
- [Issue #35: Wayfinder: adaptive harness/model routing](https://github.com/Hikari9/office-skills/issues/35) (including child decisions #44–#59, #72, #81–#85, and confirmed decisions 1–8);
- [Issue #77: Interactive planner families and multi-project orchestrator control plane](https://github.com/Hikari9/office-skills/issues/77) (including compaction addendum);
- [Issue #93: Auto Office v3 orchestrator portability](https://github.com/Hikari9/office-skills/issues/93) (including withdrawal of approval-hook enforcement);
- Accepted material findings from the independent plan review recorded in [docs/plans/v3-final-merge.md](file:///Users/rico/Git/office-skills-t0/docs/plans/v3-final-merge.md);
- And amendment-v3 requirements for derived trust, capability floors, outcome labels, and local rewards (Task T2B).

Per the plan specification (amendment v2 finding F13, amendment v3), every requirement is an individual falsifiable row carrying:
1. **Source & Decision ID** (e.g. `issue-35#decision-5`)
2. **Behavior** (one falsifiable sentence)
3. **Owning Task ID** (T0–T8, T2B, T5S)
4. **Pointer** (`path:line` in implementation or specification)
5. **Verification Command** (exact checkable command or live observation)
6. **Evidence Path or Hash**
7. **Status** (`verified | missing | conflict | external-blocker | superseded`)
8. **Disposition** (explicit approval citation for `superseded`, or blocker disposition for `external-blocker`)
